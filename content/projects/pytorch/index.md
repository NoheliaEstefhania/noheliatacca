An innovative Spanish-to-Quechua (Cusco-Collao variety) machine translation system built on a Retrieval-Augmented Generation (RAG) framework.

<!--more-->

### Overview:
Architected a machine translation system leveraging Retrieval-Augmented Generation (RAG) to address the extreme morphosyntactic complexity, rich suffixation, and vocabulary sparsity characteristic of low-resource agglutinative Andean languages.
